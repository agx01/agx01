# Architecture Decision Records

One file per decision. Each records the context, the options, the choice, and what would make us
revisit it. A decision not written down gets re-litigated every three months.

|---|---|---|

| [0002](0002-companion-repo-vs-fork.md) | Companion extension packages, not a fork | Accepted |
| [0003](0003-type-registration-strategy.md) | How out-of-tree types and enrichers register | Proposed |
| [0004](0004-separate-issuer-type.md) | A separate `Issuer` type, not upstream `Organization` | Accepted |
| [0005](0005-notes-in-markdown.md) | Notes in markdown + git, graph holds a mirror | Accepted |
| [0006](0006-registry-ids-as-merge-keys.md) | Registry identifiers as merge keys, never tickers | Accepted |
