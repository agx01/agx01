# Note templates

Copy into `vault/<type>/<slug>.md` and fill in. The YAML front matter is machine-read by
`note_to_entities` and `thesis_to_expectations` ([docs/05](../docs/05-enricher-catalog.md)), so keep
the keys; the prose below it is yours.

| Template | Use |
|---|---|
| [`thesis.md`](thesis.md) | A directional view with falsifiable expectations |
| [`company-profile.md`](company-profile.md) | What the business is and what breaks it |
| [`catalyst.md`](catalyst.md) | A dated event and what each outcome implies |
| [`evidence-note.md`](evidence-note.md) | A single cited claim bearing on a thesis |
| [`weekly-review.md`](weekly-review.md) | The query-driven review ritual |
| [`postmortem.md`](postmortem.md) | What was wrong, when the graph knew |
